# Andrea Liu 個人介紹網站與作品集

## 包含檔案
- `index.html`：個人介紹單頁式網站（已內嵌所有高畫質圖片）
- `個人作品集.pdf`：完整作品集 PDF（供網頁中的「Download the complete portfolio.」按鈕直接下載）

## 上傳至 GitHub Pages 步驟
1. 登入 GitHub，點擊右上角 `+` → **New repository**，名稱可取為 `andrea-profile`（設為 **Public**）。
2. 在新建立的 Repository 頁面點擊 **uploading an existing file**。
3. 將 `index.html` 與 `個人作品集.pdf` 一起拖曳上傳並點擊 **Commit changes**。
4. 前往 **Settings** → 左側選單 **Pages** → **Branch** 選擇 `main`（`/ (root)`）→ 點擊 **Save**。
5. 等待約 1–2 分鐘重新整理，頁面頂端會出現你的專屬網址（`https://<你的帳號>.github.io/andrea-profile/`）。
